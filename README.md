Story
This is the very beginning of your website development. You have learned the structure - now it's time to build a real page with it, save it, and see it load in a browser just like any website on the internet.
What you'll build
A single file called index.html containing:
<!DOCTYPE html> on the first line
<html> wrapping everything
<head> containing a <title> set it to My First Web Page
<body> containing two lines of text about yourself, separated by a <br>
One HTML comment explaining what your page is
Done when: the file opens in a browser, My First Web Page shows on the browser tab, and both lines of your text appear on separate lines. Only the tags taught in this lesson are needed. Headings and paragraphs come in the next lesson.
